# 证券路由按需加载设计规格

## 目标

降低应用首次打开时的 JavaScript 下载、解析和执行开销，使证券工作台及其他模块更快进入可交互状态，同时保持现有登录鉴权、云端数据边界、路由地址和页面功能不变。

## 范围

本批只处理证券项目的九类页面：证券工作台、个股分析、基金分析、智能荐股、自选股、选股器、持仓分配、策略学习实验室和预期布局雷达。根路径和 `projects/:projectId` 下的同类证券路由复用相同的延迟组件。

不修改个股分析内部逻辑、K 线与行情数据源、Supabase 数据结构、信号监控、模型参数以及投研分析页面。

## 架构

`router-base.tsx` 保留现有 `RouteObject` 结构以及 `router.tsx` 的 `RequireAuth`、`SecuritiesRouteBoundary` 包装。证券页面从静态导入改为 `React.lazy()` 动态导入，并由一个统一的 `Suspense` 路由元素包装器提供轻量加载提示。

每个页面单独使用动态导入，以便 Vite 生成独立路由 chunk。页面文件继续使用现有具名导出，通过 `.then(module => ({ default: module.NamedPage }))` 映射成 lazy 组件，不重命名页面导出。

## 错误与稳定性

延迟加载只改变模块获取时间，不改变 Provider 层级。登录鉴权先执行，证券数据 Provider 仍包裹实际页面。加载过程中显示简洁状态，避免空白页；现有路由错误处理保持不变。
