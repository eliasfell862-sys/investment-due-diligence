# 证券项目工作台视觉清晰度改造设计

## 目标

在不改变行情接口、业务计算和交互流程的前提下，提升证券项目工作台的文字可读性、内容层级和专业感。改造覆盖股票、基金、债券和 ETF 四个页签。

## 视觉方向

采用深色专业金融终端风格。主背景使用深蓝黑，内容容器使用逐级变亮的蓝灰色，强调色使用克制的青绿色。页面依靠明度、边框和间距建立层级，不依赖大面积渐变或装饰效果。

## 颜色与可访问性

- 建立仅作用于证券工作台的 CSS 主题变量，避免影响投研项目工作台。
- 主文字使用高对比浅色；次级文字仍清晰可读；弱提示文字不得与背景混合。
- 表面层级包括页面背景、一级面板、二级面板和悬浮/选中状态。
- 红色表示上涨、绿色表示下跌，保持当前 A 股习惯；数值同时保留正负号，避免只依靠颜色表达。
- 输入框、按钮、页签和可点击行提供清晰的悬停及键盘焦点状态。

## 组件调整

### 页面与页签

- 收紧过高的页面头部，使首屏更快进入数据区域。
- 页签使用独立导航容器、明确的活动态和悬停态。
- 四个资产页签共享视觉规则，但不改变原有状态管理。

### 搜索与操作区

- 搜索框、行业筛选和刷新按钮统一高度、圆角、边框及焦点样式。
- 搜索结果使用独立浮层面板，增强行悬停与已加入状态。
- 错误、加载和空状态使用统一的反馈组件样式。

### 数据表格

- 表头使用独立背景和更高对比文字，并在滚动区域内保持清晰。
- 数据行增加斑马纹、悬停态和选中态。
- 数字使用等宽数字特性，提升纵向比较效率。
- 保留横向滚动，避免窄屏压缩重要列。

### 卡片与分析面板

- 行情摘要、图表、技术指标、AI 辩论及其他分析区采用统一卡片层级。
- 卡片标题、说明、关键数值和辅助信息形成稳定的四级文字层级。
- 边框和阴影保持克制，确保高密度信息仍适合长时间阅读。

## 实现边界

- 新增证券工作台专属样式文件，并从页面引入。
- 将高频内联颜色替换为语义化 CSS 类或主题变量；布局相关的动态内联样式可保留。
- 不重构行情 API、分析引擎或业务状态。
- 不在本次改造中拆分整个千行页面；只在有助于统一视觉且风险较低时提取小型展示组件。

## 响应式设计

- 桌面端保持高密度专业终端布局。
- 中窄屏下操作区允许换行，页签支持横向滚动。
- 表格维持合理最小宽度并横向滚动，卡片网格逐级降为单列。

## 验证

- 运行现有证券工作台测试。
- 运行 TypeScript 构建，确保样式改造不影响编译。
- 检查四个页签的主文字、次级文字、表格、输入控件、卡片、错误与空状态。
- 检查常见桌面宽度和窄屏宽度，确认无明显溢出或内容遮挡。

## 验收标准

- 页面中不再出现大面积低对比度青灰文字。
- 所有主要数据、标题、表头和控件标签可快速辨认。
- 卡片、背景、选中态和悬停态之间具有明确层级。
- 股票、基金、债券和 ETF 的视觉语言一致。
- 原有功能、数据请求和计算结果保持不变。
